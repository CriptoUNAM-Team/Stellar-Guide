# escrow — Depósito condicional (lab / inscripción)

El pagador bloquea tokens en el contrato. El árbitro (profesor) `release` al beneficiario o `refund` al pagador. Un trato cerrado no se mueve otra vez.

Enseña: custodia, dos destinos posibles, transfers SAC, rol de árbitro.

SAC nativo Testnet: `CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC`

Ver invocaciones en `docs/comandos-basicos.md`.
