# enrollment — Inscripción a curso con cupo (campus)

El profesor crea la materia y el cupo. El alumno se inscribe o se da de baja. No hay doble inscripción; al llenar el cupo el siguiente `enroll` falla.

Enseña: límites (`capacity`), idempotencia del asiento, auth del estudiante.

Ver invocaciones en `docs/comandos-basicos.md`.
