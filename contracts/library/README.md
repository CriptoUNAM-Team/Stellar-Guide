# library — Préstamo de ejemplares (campus)

El profesor carga títulos y cupos. El alumno toma un ejemplar (`checkout`) y lo devuelve (`return_copy`). Un alumno no puede tener dos préstamos del mismo título.

Enseña: máquina de estados, `available`, `require_auth` del estudiante.

Ver invocaciones en `docs/comandos-basicos.md`.
